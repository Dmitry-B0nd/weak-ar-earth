КАК РЕДАКТИРОВАТЬ ТЕКСТЫ КАРТОЧЕК
================================

Два файла в этой папке:
  poi.json               — точки на Земле (космодромы, ЦУПы, станции связи, другое)
  satellites-extra.json  — станции и метеоспутники, а также общий текст для малых спутников

Правки видны сразу после обновления страницы, ничего перезапускать не нужно.


ТОЧКИ ИНТЕРЕСА (poi.json)
-------------------------

Файл открывать в VS Code или Блокноте, сохранять в кодировке UTF-8.
После правки проверить, что файл не сломан: вставить его содержимое на https://jsonlint.com
(должно быть «Valid JSON»).

Каждая точка выглядит так:

  { "id": "baikonur",            <- латиница, без пробелов, уникальный
    "type": "launch",            <- launch (космодром) / control (центр управления) / dsn (дальняя связь) / other (другое)
    "name": "Байконур",          <- заголовок карточки
    "country": "Казахстан",      <- строка под заголовком
    "lat": 45.965,               <- широта (север +, юг −)
    "lon": 63.305,               <- долгота (восток +, запад −)
    "description": "Текст…",     <- 1–3 предложения, это видит зритель
    "image": null,               <- фото: "images/baikonur.webp" или null, если фото нет
    "sats": ["МКС"] }            <- необязательно: спутники сцены, связанные с местом (кнопки в карточке);
                                    название или его начало, как в satellites.json («GOES» найдёт GOES-19)

Поля для развёрнутой карточки (кнопка «Подробнее») — необязательные:

    "facts": {                   <- короткая таблица «название: значение»
      "Основан": "1955",
      "Первый спутник": "4 октября 1957"
    },
    "details": [                 <- длинный текст, каждый абзац — отдельной строкой в кавычках
      "Первый абзац…",
      "Второй абзац…"
    ]

Короткая карточка показывает только description. Фото, facts и details видны
после нажатия «Подробнее». Если у точки нет ни фото, ни facts, ни details,
кнопка «Подробнее» не показывается. Готовые примеры — у Байконура и Кеннеди.

Правила, на которых чаще всего ломается JSON:
- Между точками — запятая, после последней точки запятой НЕТ.
- Текст — в прямых двойных кавычках "…". Внутри текста кавычки «ёлочки», не ".
- Числа (lat, lon) — без кавычек, дробная часть через точку: 45.965, а не 45,965.

Координаты проще всего взять в Яндекс/Google Картах: правый клик по месту → координаты.

Фото: только свои или со свободной лицензией (NASA, ЕКА, Wikimedia Commons),
формат WebP или JPG, около 800 px по ширине, не больше 200 КБ. Класть в папку images
рядом с index.html. Подпись автора/лицензии, если нужна, — допишите в конец description.

Тексты в файле (включая facts и details) — черновики, их нужно проверить и при желании переписать.


СПУТНИКИ (satellites-extra.json)
--------------------------------
В разделе "context" — станции и метеоспутники. У каждого можно править:
  "kind"         — тип (строка над названием карточки)
  "country"      — страна
  "description"  — короткий текст
  "facts"        — таблица фактов (как в poi.json)
  "details"      — абзацы для «Подробнее»
Не трогайте поля "key", "source", "match", "pick" — по ним скрипт находит спутник в каталоге.
Высота, скорость, виток и «над какой точкой» считаются автоматически.

В разделе "smallSat" — общий текст для всех кубсатов и малых спутников:
  "cubeDescription" / "otherDescription" — короткий текст; {year} заменяется на «, запущен в 2023 году»
  "details" — абзацы для «Подробнее» (что такое кубсат, что такое SatNOGS)
Страна, оператор, дата запуска и сайт берутся из базы SatNOGS автоматически.
